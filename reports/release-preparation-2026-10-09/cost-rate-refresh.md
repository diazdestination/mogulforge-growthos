# Public price refresh

Root browsed the [current Fly pricing page](https://fly.io/pricing/) on October9,
2026, during release preparation. It lists Basic managed Postgres at USD38/month,
storage at USD0.28/GB over30days based on database usage, and proration for mid-month
creation/deletion. The separate [October1 update page](https://fly.io/pricing-update/)
still describes provisioned storage. The current pricing page agrees more closely
with the saved October9 support answer about V2 used storage; the discrepancy
must not be silently erased or treated as an exact invoice guarantee.

The cost assessment's two-hour estimates are conditional planning arithmetic.
They omit taxes, unexpected returned sizing/tier, cleanup delays and unknown billing
rounding/minimums. The proposed new USD5 budget is an owner policy, not an API price
cap. Neither this refresh nor an existing Basic resource grants another restore.
Recheck actual returned details and lifecycle before future paid admission.
